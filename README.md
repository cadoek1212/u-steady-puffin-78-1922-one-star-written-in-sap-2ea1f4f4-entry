Entry for the [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty on [make.fun](https://make.fun/r/vx8zxx6t).

A Node 22 program (`main.ts`) that writes one line — a one-star review from a
houseplant about its human owner — to `/output/entry.txt`:

> One star: he Googled 'why is my plant dying' while standing next to me holding an empty watering can.

Run it with:

```sh
node main.ts
```
